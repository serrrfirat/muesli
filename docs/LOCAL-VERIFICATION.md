## Review corrections

Every review finding has a dedicated bug issue (#21–#33, #35–#37; #35/#36 are duplicate credential-leak reports). Applied fixes preserve concurrent notes, acknowledge pending audio, stop independently of the busy guard, report recorder errors, reject restore during capture/drain, bind Keychain credentials to canonical origins, commit endpoint configuration only after verification, and defer normal application quit for capture-tail persistence. Negative binary assertions require a specific failure reason and use the same application actions as UI. Mock clients discard live API credentials; the gate verifies a synthetic credential sentinel never reaches the mock. Fixed-width native crypto input rejects malformed hex before allocation.

Capture follow-up fixes include encrypted append before UI dispatch, a retained failed-write ledger, quit refusal until audio is durable, atomic transcription acknowledgment, unchanged-meeting rollback after failed start, session-scoped failures, and self-clearing shared stop/drain flights. State/durability review reported no findings, including the guard preventing delayed chunk callbacks from overwriting quit refusal. The positive real and mixed-source lifecycle evidence, and remaining limits, are separated above.

The strengthened capture gate tracks review bugs separately: #47 unflushed-tail shutdown proof, #48 live storage failure and actual AppKit quit refusal, #49 accurately named monotonic request timing, and #50 owned playback timeout/cleanup. Final gate review reported no findings after adding a completion handshake emitted only after the delegate's actual negative AppKit termination reply; model state alone cannot prove refusal. Gate implementation alone is not proof that a missing-microphone machine exercised those recording paths. Credential-origin isolation still requires normal-mode inference configuration proof; normal Keychain vault persistence proves vault-key storage, not API-credential isolation.

## Artifact compatibility

The native package targets macOS 14.2, but installed Homebrew libsodium/SQLCipher bottles impose newer OS requirements. This developer artifact was built with Swift 6.3.3 and exercised on macOS 26.5 only; it is not a claim that the linked binary runs on every 14.2 system. A distributable build needs dependencies built for its minimum OS and notarization. The imported upstream unit-test targets were not run; this repository's migration gate uses the actual signed application and real runtime scenarios.
